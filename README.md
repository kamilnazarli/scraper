# Polite scraper

A scraper built to practice scraping on specific website - https://books.toscrape.com/.

## Target classification

This scrapers use https://books.toscrape.com/ as a source. The main reason is that this website is a sandbox built for practicing scraping skills.
In this part, our scraper only scrapes first 3 catalogue pages only. I will not reuse this code on another site without checking its rules and terms first.

### Robots.txt check
Response to https://books.toscrape.com/robots.txt is <Response [404]>, since there is no file named like that.
